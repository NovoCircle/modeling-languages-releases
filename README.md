# modeling-languages-releases

Public releases of **Modeling Languages** from NovoCircle: one guide for each of 19 modeling languages, and one shared layout standard for sizes and spacing.

Nothing has been released yet.

## Install

Once a release exists, install it in Claude Code from the novocircle marketplace:

```
claude plugin install modeling-languages@novocircle
```

Each release also attaches `modeling-languages.plugin`, which can be uploaded in Claude chat or Cowork.

## Source

This repository holds only released plugin trees, tagged `modeling-languages--v<version>`. Source code is private.
