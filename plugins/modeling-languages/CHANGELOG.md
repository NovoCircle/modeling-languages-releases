# Changelog

## How versions change

- **Patch** (1.0.1): wording.
- **Minor** (1.1.0): new content.
- **Major** (2.0.0): a guide removed or renamed.

## 1.0.1

Wording only.

- DMN: the rule that no requirement may be held by an Input Data element now says how section 6.2.3 words it.
- UPDM: the drawing texts of the four port types (node port, resource port, service, request) are rewritten to state only what the standard's example pages show. The pages do not tell the service and request ports apart from the other port squares, and the text says so.
- Zachman, IT4IT and UPDM: the layout notes are stated as coverage, not as how the guide was read.
- TOGAF: a long list of relationships in the layout block is a block list. Its values are unchanged.
- Requirements: the rules page says "published summaries" of the standard, like the rest of the guide.
- The shared reader page for language files says what a reader finds in a file (a fact always names its section), not how the maintainers write one.
- NOTICE.md: adds a trademark line for Sparx Systems and Enterprise Architect, and names PeopleCert as the ITIL owner, as PeopleCert's own trademark statement does.
